# React Admin Dashboard

A hyper-premium, minimalist React Admin Dashboard built as a Capstone Project. This dashboard features a highly customized dark mode aesthetic, interactive data visualization, and complex data grid management, simulating an enterprise-level SaaS internal tool.

## ✨ Features

- **Premium UI/UX:** Deep dark mode (`#09090B`), glassmorphism sidebars, and high-contrast 'Inter' typography.
- **Complex Data Grids:** Advanced tables with sorting, filtering, and pagination using `@mui/x-data-grid` (Team, Contacts, Tasks).
- **Interactive Charts:** High-performance D3-based charts via `@nivo` (Line, Bar, Pie, Geography).
- **Form Validation:** Rigorous frontend validation using `Formik` and `Yup` for user creation and task assignment.
- **Calendar Management:** Drag-and-drop event management using `@fullcalendar/react`.
- **Role-Based UI:** Conceptual Role-Based Access Control (RBAC) demonstrating conditional rendering based on user roles.

## 🛠️ Tech Stack

- **Framework:** React 18
- **Routing:** React Router v6
- **UI Library:** Material-UI (MUI) v5
- **Icons:** Material Icons
- **Data Visualization:** Nivo
- **Forms:** Formik + Yup
- **Calendar:** FullCalendar
- **Fonts:** Google Fonts (Inter)

## 🚀 Getting Started

To run this project locally, follow these steps:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/prithvee07-gitlur/WEB-DEV-2-CapStone-Assignment.git
   ```
2. Navigate to the project directory:
   ```bash
   cd "WEB Dev 2 CAP/react-admin"
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```
   *(Note: You may need to use `--legacy-peer-deps` depending on your npm version due to Nivo/MUI peer dependencies).*

### Running the App

1. Start the development server:
   ```bash
   npm start
   ```
2. Open [http://localhost:3000](http://localhost:3000) to view it in your browser. The page will automatically reload when you make changes.
